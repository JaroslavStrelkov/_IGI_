Веб-сайт автосалона
Предназначени для просмотра, покупки автомобилей, получения информации о моделях, связи с автосалоном.
Целевые пользователи - люди, которые желают приобрести автомобиль

Стек технологий:
- Python 3.14.0
- Django
- SQLite
- HTML5
- Docker

Архитектура. Проект разделён на функциональные приложения, каждое из которых отвечает за определённую область системы. Основные компоненты включают каталог автомобилей, обработку заказов, промокоды, отзывы, аналитику. Подробная итерактивная карта структуры проекта содержит Django приложения, модели, представления, URL-маршруты, формы, сигналы, административные классы, связи между моделями.

[открыть итерактивную карту архитектуры](https://JaroslavStrelkov.github.io/_IGI_/architecture.html)

Модули и их назначения:
- apps.accounts Регистрация, вход и выход пользователей, управление профилем и ролями.
- apps.cars Каталог автомобилей, производители, категории, характеристики.
- apps.orders Создание и обработка заказов, позиции заказа, стоимость и статусы.
- apps.promo Промокоды, скидки и сроки действия промокодов.
- apps.reviews Функциональность отзывов.
- apps.analytics_app Аналитическая панель и представление статистики.
- apps.pages Информационные страницы сайта: контакты, вакансии, политика конфиденциальности, новости.
- core Основная конфигурация проекта и общие компоненты.

Точки интеграции:

- База данных. Доступ к данным реализован с использованием Django ORM. Модели приложений описывают основные сущности системы и связи между ними, включая пользователей, автомобили, заказы и промокоды. Тип используемой СУБД: SQLite.

- Файловая система. Приложение использует файловую систему для хранения изображений, загружаемых пользователями через поля типа ImageField в моделях Django. Изображения сохраняются в каталоге медиафайлов, настроенном через MEDIA_ROOT, и доступны через MEDIA_URL. Статические CSS-файлы в проекте не используются.

- Внешние сервисы. Веб-сайт взаимодействует с двумя внешними HTTP API: https://catfact.ninja/fact и https://dog.ceo/api/breeds/image/random

Инструкция по сборке и запуску.
1. Клонировать репозиторий и перейти в папку проекта:
git clone <https://github.com/JaroslavStrelkov/_IGI_>
cd .\IGI\LR5
2. Собрать и запустить приложение: 
docker compose up --build
3. Открыть в браузере: 
http://localhost:8000/
Для остановки приложения: docker compose down
