- Нефункциональные требования
• NFR-01 — время ответа основных страниц приложения не должно превышать 2 секунд при штатной нагрузке.  
 • Способ проверки: измерить время ответа основных страниц приложения.
 • Результат: требует измерения.
• NFR-02 — доступ к функциям управления ограничен правами пользователя.  
 • Способ проверки: проверить доступ обычного пользователя к функциям сотрудника.
 • Результат: пройдено.
• NFR-03 — функции пользователя, сотрудника и администратора разделены.  
 • Способ проверки: проверить доступ каждой роли к соответствующим функциям.
 • Результат: пройдено.
• NFR-04 — система запускается в Docker.  
 • Способ проверки: выполнить docker compose up --build.
 • Результат: пройдено.
• NFR-05 — данные хранятся в SQLite и обрабатываются через Django ORM.  
 • Способ проверки: проверить настройки базы данных и модели проекта.
 • Результат: пройдено.
• NFR-06 — сохранённые данные не теряются после перезапуска приложения.  
 • Способ проверки: создать данные, перезапустить приложение и проверить их наличие.
 • Результат: пройдено.
• NFR-07 — исходный код разделён на отдельные Django-приложения.  
 • Способ проверки: проверить структуру проекта.
 • Результат: пройдено.
• NFR-08 — проект запускается после клонирования с помощью Docker Compose.  
 • Способ проверки: клонировать репозиторий и выполнить docker compose up --build.
 • Результат: пройдено.
